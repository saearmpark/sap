실행파일(.exe) 받는 방법
  1. Releases 페이지에서 최신 버전의 *.exe 파일을 내려받습니다.
  2. 내려받은 실행파일을 원하는 폴더에 두고 더블클릭합니다. 별도 설치가 필요 없습니다.
  3. Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 선택합니다.
소스로 직접 실행 / 빌드하기
  1. Python 3.10 이상 설치 후 python -m pip install -r requirements.txt
  2. python file_renamer.py처럼 개별 파일을 실행
  3. 실행파일이 필요하면 tools/desktop 폴더에서 .\build.ps1을 실행하면 dist 폴더에 .exe가 만들어집니다.
