# SAP 학습 사이트

Java, Python, HTML/CSS를 연습하는 개인 학습 사이트입니다.

- 사이트: [GitHub Pages](https://saearmpark.github.io/sap/)
- 저장소: [saearmpark/sap](https://github.com/saearmpark/sap)

## 프로젝트 구성

```text
.
├── *.html                  # GitHub Pages 화면 (홈, 학습, 웹제작절차, 로그인, 자유 게시판, 공지사항, 게임 등)
├── assets/                 # 공통 스타일과 인증·테마·목록 렌더 스크립트
├── backend-java/
│   ├── src/main/            # Spring Boot API 소스와 설정
│   ├── src/test/            # Java API 테스트
│   └── scripts/             # PostgreSQL 백업·복구와 예약 작업
└── tools/desktop/          # PyInstaller로 빌드하는 데스크톱 학습 도구
```

정적 페이지는 GitHub Pages에서 저장소 루트 기준으로 제공하므로 HTML 파일은 루트에 둡니다. 사이트 화면은 `assets/`의 공통 스타일·인증·테마 스크립트를 공유하며, 사이드바와 소식·게시판 목록은 `common.js`·`feed.js`·`posts-page.js`로, 매뉴얼의 코드 복사 버튼은 `manual.js`로 공용화되어 있습니다. 학습 메뉴의 웹제작절차(`manual.html`)는 웹사이트 기획과 VS Code 설치부터 HTML/CSS/JavaScript/Python 제작, 페이지 연결, 서버 업데이트, AI CLI 활용, 첫 웹사이트 완성까지 10개 가이드로 안내합니다. 회원가입하면 바로 로그인할 수 있으며, 게시판·자료실·실시간 대화는 로그인해야 이용할 수 있습니다. 일정도 로그인한 계정별로 저장됩니다. 실시간 대화는 공용방·1:1 메시지와 사용자 접속 상태를 제공하고 대화는 2일간 보관합니다. 관련 API는 Java 백엔드에 있습니다.

이슈사항 페이지(`news.html`)는 무료 RSS에서 경제·스포츠·연예를 제외한 국내 정치·사회 소식을 10분마다 자동으로 수집하며 같은 사건을 다룬 중복 제목은 걸러 내고 최신 20건을 썸네일과 함께 보여주고, 무료 오픈메테오(Open-Meteo) API와 오픈스트리트맵 지도로 서울·부산·대구·인천·광주·대전·천안의 오늘 날씨(현재 기온, 최고/최저, 강수확률, 오전·오후 예상 기온)를 표시하며, 지도 아래에는 천안의 시간대별 강수확률과 예상 기온을 함께 보여줍니다. 투자정보 페이지(`stocks.html`)는 삼성전자·SK하이닉스·SK스퀘어 등 국내 시가총액 상위 3개와 KODEX 200, 엔비디아·애플·알파벳 등 미국 시가총액 상위 3개와 S&P 500(SPY)·나스닥 100(QQQ) ETF, 원/달러 환율, 비트코인, 금 ETF, WTI 유가 시세를 10초마다 갱신하며, 정규장 밖의 장전·시간외 값은 배지로 구분하고 장이 닫힌 종목은 '장 마감' 배지로, 일부 소스가 늦으면 '일부 시세 지연' 안내로 표시합니다. 같은 페이지에는 주식·금리·환율·코인·미국 증시·연준 등 경제 분류 소식도 함께 표시합니다. 두 페이지는 마지막으로 받은 정보를 브라우저에 저장해 두고, 서버가 잠들어 있어도 저장된 데이터를 즉시 먼저 보여준 뒤 새 데이터로 갱신합니다. 게임 제작 페이지는 43개의 실습 게임과 코드 보기를 제공합니다. 기록 게임은 로그인 계정별 최고 기록과 상위 10명 랭킹을 보여주며, 반응 속도·지뢰 찾기처럼 낮을수록 좋은 기록은 빠른 순서로 정렬합니다. 끝말잇기에서 사용자가 첫 글자 불일치·중복·형식 오류·이어가기 불가능한 단어를 말하면 패배로 처리됩니다. 시작 버튼이 있는 게임은 Enter 키로도 시작할 수 있습니다. 온라인 틱택토는 짧은 연결 끊김이나 백엔드 재시작 후에도 60초 안에 재접속하면 진행 상태를 복구합니다.

로그인 후 `mypage.html`에서 내 글·자료·그림과 다가오는 일정을 한눈에 볼 수 있습니다. `search.html`은 게임·앱·웹제작절차·소식(이슈사항·투자정보), 그리고 로그인 시 게시판·자료실까지 검색합니다. 자유 게시판은 검색·글 수정과 댓글을 지원하고, 소통 메뉴의 공지사항 페이지에서는 관리자가 공지를 작성합니다. 자료실은 파일명·태그·작성자 검색, 태그, 다운로드 횟수 집계와 드래그 업로드를 제공합니다. 일정은 반복(매일·매주·매월)과 ICS 내보내기를 지원합니다.

## 로컬 실행

### 웹 화면

저장소 루트에서 VS Code Live Server로 `index.html`을 엽니다. 게시판과 자료실 API를 사용하려면 아래 Java 서버도 실행해야 합니다.

### Java API

JDK 17 이상이 필요합니다. 터미널에서:

```bash
cd backend-java
mvn spring-boot:run
```

기본 주소는 `http://127.0.0.1:8080`이며, 로컬 기본 데이터베이스는 `backend-java/data/` 아래의 H2 파일입니다. 자세한 API와 저장 방식은 [`backend-java/README.md`](backend-java/README.md)를 참고하세요.

## 배포 및 데이터 참고

- GitHub Pages는 루트 HTML과 `assets/`의 정적 파일을 제공합니다.
- 게시판·자료실 프론트엔드는 Render의 Java API를 사용합니다.
- 게시글과 Java 자료실 파일은 JPA를 통해 설정된 데이터베이스에 저장됩니다. Render 서버가 재시작되거나 재배포되어도 DB에 저장한 파일은 유지됩니다.
- Java PostgreSQL DB는 `backend-java/scripts/backup-postgres.ps1`로 백업하고, 별도 스테이징 DB에서 복구를 시험할 수 있습니다. 자세한 운영 절차와 보안 주의사항은 [`backend-java/README.md`](backend-java/README.md)를 참고하세요.
- Java 백엔드 테스트는 GitHub Actions에서 자동 실행됩니다. 정적 페이지의 공용·인라인 스크립트 문법도 GitHub Actions에서 검사합니다. Windows에서 주간 DB 백업 예약을 설정하는 방법은 백엔드 README를 참고하세요.
- 계정 비밀번호는 BCrypt로 해시해 저장하고, 7일 유효 인증 토큰은 DB에 해시 형태로 저장합니다. 계정과 일정은 JPA 데이터베이스에 저장됩니다.
- 첫 관리자 계정은 Render 환경변수 `SAP_ADMIN_USERNAME`, `SAP_ADMIN_PASSWORD`로 설정합니다. 승인 페이지는 관리자로 로그인하면 메뉴에 표시됩니다.
- `target/`, `uploads/`, Python 캐시와 로컬 DB 파일은 생성되거나 개발 환경에 종속되므로 Git 추적에서 제외합니다.
