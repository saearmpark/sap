전략 시뮬레이션

일꾼으로 미네랄을 모으고, 병영과 공장을 지어 군대를 만든 뒤 적 사령부를 파괴하는 미니 RTS입니다. 한 판은 5~10분 정도이며, 모든 전투는 이 페이지 안에서 실시간으로 진행됩니다.

미네랄 0 인구 0/20 시간 00:00 적 사령부 -

미니 전략 시뮬레이션

일꾼이 자동으로 미네랄을 채취합니다. 병영을 지어 해병을 뽑고, 적 사령부를 파괴하세요. 시작 후 왼쪽 클릭으로 선택하고 오른쪽 클릭으로 이동·공격을 지시할 수 있습니다.

유닛이나 건물을 선택하세요.
미니맵 클릭 → 선택 유닛 이동

전투 시작 버튼을 눌러주세요.

조작과 규칙

조작동작
왼쪽 클릭유닛·건물 선택, 빈 곳 클릭 시 선택 해제
왼쪽 드래그여러 유닛 상자 선택

A → 클릭공격 이동 — 이동 중 만나는 적과 싸웁니다.
S / Esc정지 / 건설·공격 이동 취소 및 선택 해제
P일시정지
모바일 탭유닛 선택 후 빈 곳을 탭하면 이동, 적을 탭하면 공격
  • 승리 — 적 사령부를 파괴합니다. 패배 — 내 사령부가 파괴됩니다.
  • 일꾼은 명령하지 않아도 가장 가까운 미네랄에서 자동으로 채취합니다.
  • 병영은 해병, 공장은 탱크를 생산합니다. 탱크는 느리지만 사거리가 깁니다.
  • 인구 한도는 20입니다. 유닛을 너무 많이 뽑으면 더 이상 생산할 수 없습니다.
  • 초반에는 일꾼을 6~8기까지 늘리고, 병영을 먼저 지어 방어할 군대를 확보하세요.
  • 휴대폰에서는 화면을 가로로 돌리면 전장이 더 넓게 보입니다.
