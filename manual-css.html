웹제작절차 04

CSS 제작

CSS는 HTML 뼈대에 색·간격·글꼴·배치를 입히는 언어입니다. 이 단계에서는 스타일을 연결하는 방법부터 Flex·Grid 레이아웃, 모바일 대응, 다크 모드까지 익힙니다.

난이도 · 초급 예상 시간 · 30분 준비물 · HTML 페이지

1. CSS를 HTML에 연결하기

가장 좋은 방법은 별도 .css 파일을 만들어 <head>에서 불러오는 것입니다. 여러 페이지가 같은 파일을 공유할 수 있고 캐시도 활용됩니다.

index.html 
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="assets/style.css?v=labels-41">
</head>
assets/style.css 
body {
  margin: 0;
  font-family: system-ui, -apple-system, "Segoe UI", sans-serif;
  line-height: 1.6;
  color: #222;
  background: #fafafa;
}

?v=labels-41은 캐시 버전입니다. CSS를 크게 바꿨는데 브라우저가 예전 파일을 계속 쓰는 것 같으면 이 값을 올립니다.

2. 선택자와 우선순위

CSS 
/* 태그 */
p { color: #444; }

/* 클래스: 여러 요소에 재사용 */
.note { padding: 12px; background: #fff8dc; }

/* 아이디: 페이지에 하나만 */
#main-title { font-size: 32px; }

/* 특정 부모 안의 요소 */
.card h3 { margin-top: 0; }

/* 마우스를 올렸을 때 */
a:hover { text-decoration: underline; }

/* 키보드 포커스 */
button:focus-visible { outline: 2px solid #2f6fed; }

같은 요소에 스타일이 겹치면 보통 나중에 쓴 규칙, 더 구체적인 선택자, 인라인 style 순으로 이깁니다. !important는 문제를 덮기만 하므로 되도록 쓰지 않습니다.

3. 박스 모델: 여백의 기본

모든 요소는 내용(content) · 안쪽 여백(padding) · 테두리(border) · 바깥 여백(margin)으로 이루어집니다. box-sizing: border-box를 쓰면 지정한 너비 안에 padding과 border가 포함됩니다.

CSS 
*, *::before, *::after {
  box-sizing: border-box;
}

.card {
  width: 320px;
  padding: 20px 22px;
  margin-bottom: 14px;
  border: 1px solid #ddd;
  border-radius: 10px;
  background: #fff;
}

/* 위/아래는 0, 좌/우는 자동 → 가운데 정렬 */
.container {
  max-width: 920px;
  margin: 0 auto;
  padding: 0 20px;
}
TIP

margin은 요소 바깥을 밀어내고, padding은 요소 안쪽을 넓힙니다. 여백이 이상하면 개발자도구에서 초록색/주황색 영역을 확인하세요.

4. Flexbox로 한 줄 배치

메뉴, 버튼 줄, 카드 안의 아이콘+글처럼 한 방향 배치에는 Flexbox가 편합니다.

CSS 
.toolbar {
  display: flex;
  align-items: center;      /* 세로 가운데 */
  justify-content: space-between; /* 양끝 배치 */
  gap: 12px;                /* 요소 사이 간격 */
  flex-wrap: wrap;          /* 좁으면 다음 줄로 */
}

.toolbar .grow {
  flex: 1;                  /* 남는 공간을 모두 차지 */
}
HTML 
<div class="toolbar">
  <h2>게시판</h2>
  <input class="grow" type="search" placeholder="검색">
  <button type="button">검색</button>
</div>

5. Grid로 카드 배치

같은 크기의 카드를 여러 줄로 배치할 때는 Grid가 깔끔합니다. auto-fit과 minmax를 쓰면 화면 너비에 따라 열 수가 자동으로 바뀝니다.

CSS 
.manual-toc {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(230px, 1fr));
  gap: 12px;
}

.manual-toc-card {
  padding: 16px 18px;
  border: 1px solid #ddd;
  border-radius: 10px;
  background: #fff;
}

1fr은 “남는 공간을 같은 비율로 나눈다”는 뜻입니다. 카드가 너무 넓어지면 max-width를 함께 지정합니다.

6. 반응형: 화면 크기에 맞추기

모바일에서는 옆 메뉴를 위로 올리고, 여러 열을 한 열로 바꿉니다. 미디어 쿼리는 파일 아래쪽에 모아 두면 찾기 쉽습니다.

CSS 
@media (max-width: 760px) {
  .layout {
    flex-direction: column;
  }

  .sidebar {
    width: 100%;
  }

  .manual-toc {
    grid-template-columns: 1fr;
  }

  .main {
    padding: 24px 14px;
  }
}
주의

글자가 너무 작아지지 않게 하려면 고정 px보다 rem이 유리합니다. 이미지에는 max-width: 100%; height: auto;를 기본으로 두세요.

7. CSS 변수와 다크 모드

이 사이트처럼 색을 변수로 정의하면 테마 전환이 간단해집니다. :root에 기본값을 두고, 다크 모드에서 변수만 바꿉니다.

CSS 
:root {
  --bg: #fafafa;
  --surface: #ffffff;
  --ink: #222222;
  --ink-soft: #666666;
  --border: #dddddd;
  --accent: #2f6fed;
}

html[data-theme="dark"] {
  --bg: #17181b;
  --surface: #202226;
  --ink: #f2f3f5;
  --ink-soft: #a9adb5;
  --border: #34373d;
  --accent: #7aa2ff;
}

body {
  background: var(--bg);
  color: var(--ink);
}

.card {
  background: var(--surface);
  border: 1px solid var(--border);
  color: var(--ink);
}

테마 값은 document.documentElement.dataset.theme = "dark"처럼 html의 data-theme 속성을 바꿔 적용합니다. 새로고침 전에 저장하려면 localStorage를 사용합니다(05장).

8. 상태와 전환 효과

CSS 
.button {
  padding: 9px 14px;
  border: 1px solid var(--border);
  border-radius: 8px;
  background: var(--surface);
  color: var(--ink);
  cursor: pointer;
  transition: border-color 0.18s ease, background-color 0.18s ease;
}

.button:hover {
  border-color: var(--accent);
}

.button:active {
  transform: translateY(1px);
}

.button:disabled {
  opacity: 0.55;
  cursor: not-allowed;
}

전환 효과는 짧게(0.15~0.25초) 줍니다. 움직임을 줄이고 싶은 사용자를 위해 @media (prefers-reduced-motion: reduce)에서 transition: none을 지정할 수도 있습니다.

9. 스타일이 안 먹을 때

  • 경로 확인 — <link href>가 실제 파일 위치와 같은지 봅니다. assets/style.css는 HTML과 같은 폴더의 assets 안입니다.
  • 선택자 확인 — HTML의 class 이름과 CSS의 .이름이 정확히 같은지 봅니다. 대소문자를 구분합니다.
  • 캐시 확인 — Ctrl + F5 또는 버전 쿼리를 올립니다.
  • 개발자도구 — F12 → Elements에서 요소를 고르면 적용된 규칙과 덮어쓴 규칙(취소선)이 보입니다.

10. 읽기 쉽고 접근성 좋은 화면

예쁜 것보다 먼저 읽기 편해야 합니다. 글자 크기와 줄 간격, 대비, 키보드 포커스를 기본값으로 정해 두면 페이지마다 흔들리지 않습니다.

CSS 
body {
  font-size: 16px;
  line-height: 1.7;
  color: #1f2937;
  background: #ffffff;
}

.article {
  max-width: 68ch;   /* 한 줄이 너무 길어지지 않게 */
}

a {
  color: #0b5cad;
  text-underline-offset: 3px;
}

a:focus-visible,
button:focus-visible {
  outline: 3px solid #b45309;
  outline-offset: 2px;
}

img {
  max-width: 100%;
  height: auto;
}

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}
  • 본문은 16px 이상, 줄 간격은 1.6~1.8이 읽기 편합니다. 한 줄은 대략 45~75자로 유지합니다.
  • 본문 글자와 배경의 대비는 4.5:1 이상을 목표로 합니다. 연한 회색 글자는 특히 주의합니다.
  • 링크·버튼의 기본 포커스 표시를 지웠다면 반드시 대체 표시를 넣습니다.
  • 다크 모드는 색을 단순히 반전하지 말고, 어두운 배경에서도 대비를 다시 확인합니다.
  • 이미지는 max-width: 100%로 화면 밖으로 넘치지 않게 합니다.

완료 체크리스트

  • 외부 CSS 파일을 만들어 HTML에 연결했다.
  • 클래스 선택자로 카드 스타일을 만들었다.
  • Flexbox로 가로 배치를, Grid로 카드 배치를 해 봤다.
  • 760px 이하에서 한 열로 바뀌는 반응형 규칙을 넣었다.
  • CSS 변수로 색을 관리하고 다크 모드 값을 따로 정의했다.
  • 본문 크기·줄 간격·대비와 키보드 포커스를 점검했다.
