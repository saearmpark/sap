웹개발 학습

기초를 익히고 작은 결과물을 만들며 웹개발을 단계별로 연습합니다. 각 단계의 실습 결과는 게시판에 기록하고, 예제 파일은 자료실에 보관해보세요.

HTML · 페이지 구조

문서의 의미와 콘텐츠 구조를 만듭니다.

  • 제목, 문단, 링크, 이미지, 목록
  • 폼과 입력 요소, 시맨틱 태그
  • 실습: 자기소개 페이지 만들기

CSS · 화면 디자인

글꼴, 색상, 간격과 반응형 레이아웃을 익힙니다.

  • 선택자와 박스 모델
  • Flexbox, Grid, 미디어 쿼리
  • 실습: 모바일에서도 읽기 편한 카드형 화면

JavaScript · 상호작용

사용자 입력에 반응하고 화면을 동적으로 바꿉니다.

  • 변수, 조건문, 반복문, 함수
  • DOM과 이벤트 처리
  • 실습: 할 일 목록과 간단한 퀴즈

데이터와 API

브라우저와 서버 사이에서 데이터를 주고받습니다.

  • JSON, HTTP 요청과 응답
  • Fetch와 비동기 처리
  • 실습: 게시판 목록을 불러오고 새 글 등록하기

Git · 배포와 프로젝트

변경 이력을 관리하고 웹사이트를 공개합니다.

  • 저장소, 커밋, 브랜치
  • 정적 페이지와 백엔드 배포의 차이
  • 실습: 작은 웹앱을 완성해 GitHub Pages에 게시하기
