웹제작절차 06

파이썬 제작

Python은 반복 작업을 자동화하고, 파일을 정리하고, 작은 데스크톱 도구를 만드는 데 편한 언어입니다. 정적 웹사이트 제작에는 필수가 아니지만, 이미지·데이터·링크를 한꺼번에 점검할 때 큰 도움이 됩니다. 설치부터 가상환경, 패키지, 파일 처리, 실행파일 만들기까지 순서대로 진행합니다.

난이도 · 초급 예상 시간 · 40분 준비물 · Windows PC

1. Python 설치

  1. 공식 사이트에서 내려받습니다. python.org/downloads에서 최신 안정 버전(3.12 이상)의 Windows 설치 파일을 받습니다.
  2. PATH 옵션을 체크합니다. 설치 첫 화면의 Add python.exe to PATH를 반드시 체크한 뒤 Install Now를 누릅니다.
  3. 설치를 확인합니다. 새 터미널에서 아래 명령을 실행합니다.
PowerShell 
py --version
python --version

Python 3.x.x가 출력되면 성공입니다. py는 Windows용 실행기이고, python은 PATH에 등록했을 때 동작합니다.

2. 첫 스크립트 실행

VS Code에서 hello.py를 만들고 아래처럼 입력합니다. 터미널에서 파일이 있는 폴더로 이동한 뒤 실행하세요.

hello.py 
name = input("이름을 입력하세요: ")
print(f"안녕하세요, {name}님!")
PowerShell 
python hello.py
TIP

VS Code에서 Python 확장을 설치하면 오른쪽 위 실행 버튼으로도 실행할 수 있습니다. 다만 입력을 받는 프로그램은 터미널에서 실행하는 편이 확실합니다.

3. 변수·조건·반복·함수

basic.py 
site = "사피엔스"
count = 3

if count >= 3:
    print(f"{site}에 {count}번 방문했습니다.")
else:
    print("조금 더 둘러보세요.")

for number in range(1, 4):
    print(number)

def greet(name):
    return f"안녕하세요, {name}님"

print(greet("사피엔스"))

Python은 들여쓰기(보통 공백 4칸)가 문법입니다. if, for, def 다음 줄은 반드시 같은 깊이로 들여쓰세요.

4. 파일 읽기와 JSON 저장

한글 파일은 encoding="utf-8"을 명시하는 것이 안전합니다.

files.py 
import json
from pathlib import Path

source = Path("memo.txt")
source.write_text("첫 줄\n둘째 줄\n", encoding="utf-8")

text = source.read_text(encoding="utf-8")
print(text)

data = {"site": "사피엔스", "visits": 3}
Path("data.json").write_text(
    json.dumps(data, ensure_ascii=False, indent=2),
    encoding="utf-8"
)

loaded = json.loads(Path("data.json").read_text(encoding="utf-8"))
print(loaded["visits"])

Path는 현재 폴더 기준 경로를 다루기 쉽게 해 줍니다. 파일이 없을 때를 대비하려면 try/except FileNotFoundError로 감쌉니다.

5. 가상환경 만들기

프로젝트마다 필요한 패키지를 따로 관리하려면 가상환경을 사용합니다. 프로젝트 폴더에서 아래 순서로 실행합니다.

PowerShell 
py -m venv .venv
.\.venv\Scripts\Activate.ps1

# 프롬프트 앞에 (.venv)가 붙으면 활성화된 상태
python --version

# 작업이 끝나면
deactivate
오류가 난다면

“스크립트를 실행할 수 없습니다”가 나오면 현재 터미널에만 적용되는 정책 완화를 실행한 뒤 다시 활성화하세요.

PowerShell 
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

-Scope Process는 이 터미널 창에만 적용되며 시스템 전체 설정을 바꾸지 않습니다. .venv 폴더는 Git에 올리지 않습니다.

6. 패키지 설치와 requirements.txt

PowerShell 
# 가상환경이 활성화된 상태에서
python -m pip install requests

# 현재 환경의 패키지 목록 저장
python -m pip freeze > requirements.txt

# 다른 컴퓨터에서 같은 환경 재현
python -m pip install -r requirements.txt

pip를 직접 부르기보다 python -m pip로 실행하면 여러 Python 버전이 설치된 PC에서도 현재 인터프리터에 정확히 설치됩니다.

7. 자동화 예제: 텍스트 파일 집계

폴더 안의 .txt 파일을 읽어 줄 수와 단어 수를 세는 작은 도구입니다. 업무에서 반복되는 집계 작업을 이렇게 바꿀 수 있습니다.

count_text.py 
from pathlib import Path

folder = Path(".")
rows = []

for file in folder.glob("*.txt"):
    text = file.read_text(encoding="utf-8")
    rows.append((file.name, len(text.splitlines()), len(text.split())))

rows.sort()
for name, lines, words in rows:
    print(f"{name}: {lines}줄, {words}단어")

print(f"총 {len(rows)}개 파일")
참고

파일을 삭제·이동하는 자동화는 위험합니다. 먼저 미리보기만 출력하고, 확인 후 실제 작업을 실행하도록 두 단계로 나누세요.

8. 실행파일(.exe) 만들기

Python이 설치되지 않은 PC에서도 실행하려면 PyInstaller로 묶습니다. 이 저장소의 데스크톱 도구도 같은 방식을 사용합니다.

PowerShell 
python -m pip install pyinstaller

pyinstaller --onefile --noconsole tool.py

# 결과: dist\tool.exe

이 저장소에서는 tools/desktop 폴더에서 .\build.ps1을 실행하면 각 도구가 Windows 실행파일로 패키징됩니다. build, dist, *.spec 같은 생성물은 커밋하지 않습니다.

주의

실행파일은 백신이 오탐할 수 있습니다. 배포 전에 서명·출처 안내를 준비하고, 사용자에게 파일의 출처를 명확히 알려 주세요.

9. 웹사이트와 Python의 역할 구분

브라우저는 HTML·CSS·JavaScript를 실행하지만 Python은 직접 실행하지 않습니다. Python은 웹사이트를 만들거나 점검하는 내 컴퓨터 쪽 도구, 또는 별도로 실행되는 서버에서 사용합니다.

하고 싶은 일사용하는 곳
화면 구성과 클릭 동작브라우저의 HTML·CSS·JavaScript
이미지 이름·크기 일괄 정리내 PC의 Python 스크립트
데이터로 HTML 표 생성내 PC의 Python 스크립트
회원·게시글 저장 API서버에서 실행되는 Python/Java
GitHub Pages 배포정적 파일만 배포 (Python 실행 안 함)
check_pages.py 
from pathlib import Path

root = Path(".")
for path in sorted(root.rglob("*.html")):
    print(path)

print(f"HTML 파일 {len(list(root.rglob('*.html')))}개")

이런 스크립트로 페이지 목록을 뽑거나, 이미지 용량을 줄이거나, 깨진 링크를 찾을 수 있습니다. 반대로 로그인·결제·게시글 저장처럼 브라우저 밖에서 데이터를 보관해야 한다면 서버가 필요합니다. Flask·FastAPI로 만든 서버는 GitHub Pages가 아니라 Render 같은 서버 호스팅에 올리고, 프런트엔드에서 fetch로 호출합니다.

주의

API 키나 데이터베이스 비밀번호를 HTML·JavaScript·배포용 실행파일에 넣지 마세요. 서버의 환경 변수에 보관하고, 공개 저장소에는 예시 값만 둡니다.

완료 체크리스트

  • py --version으로 Python 설치를 확인했다.
  • hello.py를 만들어 실행했다.
  • 가상환경을 만들고 활성화·비활성화했다.
  • requirements.txt로 패키지 목록을 저장했다.
  • 텍스트 파일을 읽어 결과를 출력하는 스크립트를 작성했다.
  • PyInstaller의 역할과 생성물을 커밋하지 않는 이유를 이해했다.
  • 브라우저는 Python을 실행하지 않으며, 서버가 필요한 경우를 구분할 수 있다.
