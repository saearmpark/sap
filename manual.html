웹제작절차

웹사이트를 처음 만드는 분을 위한 10단계 절차입니다. 무엇을 만들지 기획하는 것부터 시작해 HTML·CSS·JavaScript로 화면을 만들고, Python 자동화와 페이지 연결, GitHub Pages 배포, AI CLI 활용까지 거친 뒤 첫 웹사이트를 완성합니다. 각 단계는 15~40분이면 끝나도록 나누어 두었습니다.

01 기획 → 02 도구 → 03 뼈대 → 04 디자인 → 05 동작 → 06 자동화 → 07 연결 → 08 배포 → 09 AI 활용 → 10 완성
TIP

처음이라면 01번부터 순서대로 진행하세요. 각 페이지의 검은 코드 상자는 오른쪽 위 복사 버튼으로 그대로 붙여 넣을 수 있습니다.

이 절차로 만드는 것

  • 목표·페이지 목록·폴더 구조가 있는 기획서
  • 내 컴퓨터에서 직접 열어 보는 웹 페이지
  • HTML·CSS·JavaScript로 만든 반응형 화면
  • Python으로 반복 작업을 자동화하는 도구
  • GitHub Pages에 올린 나만의 웹사이트
  • AI CLI와 함께 안전하게 수정·검증하는 습관

진행 방법

  1. 한 번에 한 단계만 따라 하고, 화면을 직접 확인합니다.
  2. 오류가 나면 멈추고 메시지를 그대로 읽어 봅니다. 대부분 파일 위치나 오타 문제입니다.
  3. 내 것으로 만들기 익숙해지면 내 문구·색·기능으로 바꿔 보세요. 그것이 진짜 학습입니다.

참고

06 파이썬은 정적 웹사이트 제작에 꼭 필요하지는 않습니다. 반복 작업을 자동화하거나 데스크톱 도구를 만들 때 유용합니다. 웹사이트를 먼저 완성하고 싶다면 01~05, 07~08, 10단계를 따라가도 됩니다.

막혔을 때 확인할 것

  • 파일이 안 보여요 — VS Code에서 올바른 폴더(예: D:\sap)를 열었는지 확인하세요.
  • 화면이 그대로예요 — 저장(Ctrl + S) 후 브라우저에서 Ctrl + F5로 새로고침하세요.
  • 스타일이 안 먹어요 — <link> 경로와 파일명 대소문자를 확인하세요.
  • 이미지가 깨져요 — src 경로, 파일 확장자, 파일명 대소문자가 실제 파일과 같은지 확인하세요.
  • 링크가 404예요 — 페이지 파일이 같은 폴더에 있는지, .html 확장자와 철자가 맞는지 확인하세요.
  • 터미널 명령이 안 돼요 — 현재 폴더가 맞는지 pwd(PowerShell은 Get-Location)로 확인하세요.
  • 배포가 안 보여요 — GitHub Actions가 끝났는지, 캐시 버전을 올렸는지 확인하세요.
