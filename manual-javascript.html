자바스크립트 제작

JavaScript는 페이지에 동작을 붙입니다. 버튼을 눌렀을 때 반응하고, 입력값을 검사하고, 데이터를 저장하거나 서버에서 가져오는 일을 합니다. 이 단계에서는 작은 기능을 직접 완성해 봅니다.

난이도 · 초급 예상 시간 · 35분 준비물 · HTML/CSS 페이지

1. JavaScript 연결하기

스크립트는 보통 </body> 바로 앞에 둡니다. HTML 요소가 모두 만들어진 뒤에 실행되므로 요소를 찾지 못하는 오류를 줄일 수 있습니다.

HTML 
<button id="hello-button" type="button">인사하기</button>
<p id="hello-output"></p>

<script src="assets/practice.js"></script>
assets/practice.js 
const button = document.querySelector("#hello-button");
const output = document.querySelector("#hello-output");

button.addEventListener("click", () => {
  output.textContent = "안녕하세요!";
});

2. 값, 변수, 조건, 함수

JavaScript 
const siteName = "사피엔스";   // 바뀌지 않는 값
let count = 0;                // 바뀌는 값

count = count + 1;

if (count >= 3) {
  console.log("세 번 이상 실행됨");
} else {
  console.log("아직 부족함");
}

function greet(name) {
  return `안녕하세요, ${name}님`;
}

console.log(greet("사피엔스"));

문자열은 "...", 숫자는 123, 참/거짓은 true/false입니다. 백틱(`)으로 감싼 문자열 안에는 ${값}을 넣어 변수를 섞을 수 있습니다.

보안

사용자가 입력한 값을 화면에 표시할 때는 innerHTML 대신 textContent를 사용하세요. innerHTML은 입력값 안의 태그·스크립트를 실행할 수 있습니다.

4. 이벤트: 클릭과 제출

JavaScript 
const form = document.querySelector("#contact-form");
const message = document.querySelector("#form-message");

form.addEventListener("submit", (event) => {
  event.preventDefault(); // 페이지 새로고침 막기

  const nameInput = document.querySelector("#name");
  const name = nameInput.value.trim();

  if (!name) {
    message.textContent = "이름을 입력해 주세요.";
    nameInput.focus();
    return;
  }

  message.textContent = `${name}님, 전송 준비가 되었습니다.`;
  form.reset();
});

preventDefault()는 폼의 기본 동작(새로고침)을 막습니다. 실제 서버 전송은 아래 fetch와 함께 사용합니다.

5. localStorage로 값 저장하기

브라우저를 닫아도 유지할 간단한 설정은 localStorage에 저장합니다. 값은 항상 문자열로 저장되므로 숫자는 Number()로 바꿔 읽습니다.

JavaScript 
// 저장
localStorage.setItem("sap-theme", "dark");

// 읽기
const savedTheme = localStorage.getItem("sap-theme");

// 삭제
localStorage.removeItem("sap-theme");

// 객체는 JSON으로 변환
const settings = { font: "large", sidebar: true };
localStorage.setItem("sap-settings", JSON.stringify(settings));

const loaded = JSON.parse(localStorage.getItem("sap-settings") || "{}");
console.log(loaded.font);

비밀번호, 주민번호, 인증 토큰처럼 민감한 정보는 localStorage에 저장하지 않습니다.

6. fetch로 서버 데이터 가져오기

다른 서버의 데이터를 읽을 때는 fetch와 async/await를 사용합니다. 네트워크 오류와 서버 오류를 모두 처리해야 화면이 멈추지 않습니다.

JavaScript 
async function loadNews() {
  const status = document.querySelector("#news-status");
  const list = document.querySelector("#news-list");

  status.textContent = "불러오는 중...";

  try {
    const response = await fetch("https://board-backend-nngx.onrender.com/api/news");
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    const items = await response.json();
    list.replaceChildren();

    items.forEach((item) => {
      const li = document.createElement("li");
      const link = document.createElement("a");
      link.href = item.link;
      link.textContent = item.title;
      link.target = "_blank";
      link.rel = "noopener";
      li.appendChild(link);
      list.appendChild(li);
    });

    status.textContent = `${items.length}건을 불러왔습니다.`;
  } catch (error) {
    status.textContent = "데이터를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요.";
    console.error(error);
  }
}

loadNews();
TIP

서버가 처음 깨어나는 동안에는 응답이 느릴 수 있습니다. 로딩 문구를 먼저 보여 주고, 실패하면 재시도 버튼을 제공하면 사용자 경험이 좋아집니다.

7. 오류 찾기

  • F12 → Console에서 빨간 오류 메시지와 줄 번호를 확인합니다.
  • F12 → Sources에서 코드 줄 번호를 눌러 중단점을 걸고 한 줄씩 실행할 수 있습니다.
  • 값이 예상과 다르면 console.log(값)으로 직접 출력해 봅니다.
  • document.querySelector 결과가 null이면 id/class 이름 또는 스크립트 실행 순서를 확인합니다.

오류 메시지의 첫 줄이 원인인 경우가 많습니다. “Cannot read properties of null”은 대부분 요소를 찾지 못했다는 뜻입니다.

8. 안전하게 작성하는 습관

  • 사용자 입력은 textContent로 출력하고, 꼭 필요한 경우에만 살균된 HTML을 사용합니다.
  • API 주소와 키를 코드에 직접 쓰지 말고, 공개 가능한 값인지 먼저 확인합니다.
  • 버튼을 여러 번 눌러도 중복 요청이 가지 않도록 disabled 처리나 로딩 상태를 둡니다.
  • 실패했을 때 사용자가 무엇을 해야 하는지 화면에 문장으로 알려 줍니다.

9. 폼 데이터는 어디로 갈까요?

지금까지 만든 폼은 브라우저 안에서만 동작합니다. 새로고침하면 입력값이 사라지고, 다른 사람과 공유되지도 않습니다. 입력값을 저장하거나 다른 사람에게 보내려면 서버가 필요합니다.

브라우저 폼 → fetch → 서버 API → 데이터베이스

GitHub Pages는 HTML·CSS·JS 같은 정적 파일만 제공하며 Python이나 Java 서버 코드를 실행하지 않습니다. 서버는 별도 호스팅(예: Render)이나 학교·회사 서버에 두고, 프런트엔드에서는 그 API 주소로 요청합니다.

JavaScript 
async function sendMessage(payload) {
  const response = await fetch("/api/messages", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload)
  });

  if (!response.ok) {
    throw new Error(`저장 실패: HTTP ${response.status}`);
  }

  return response.json();
}

document.querySelector("#contact-form").addEventListener("submit", async (event) => {
  event.preventDefault();
  const form = new FormData(event.currentTarget);

  try {
    await sendMessage({
      name: form.get("name"),
      message: form.get("message")
    });
    alert("전송했습니다.");
  } catch (error) {
    console.error(error);
    alert("전송하지 못했습니다. 잠시 후 다시 시도해 주세요.");
  }
});
중요

/api/messages는 설명을 위한 예시 주소입니다. 실제로는 그 주소를 제공하는 서버가 있어야 하며, 이 저장소의 API는 로그인이나 권한이 필요한 경우가 있습니다. 서버 배포와 환경 변수는 08 · 서버 업데이트에서 다룹니다.

완료 체크리스트

  • 버튼 클릭으로 화면 글자가 바뀌게 했다.
  • 폼 제출을 막고 입력값을 검사했다.
  • textContent로 요소를 추가했다.
  • localStorage에 값을 저장하고 다시 읽었다.
  • fetch 실패 상황을 try/catch로 처리했다.
  • 데이터를 영구 저장하려면 서버와 데이터베이스가 필요함을 이해했다.
