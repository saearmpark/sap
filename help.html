메뉴별 기능

  • 홈 — 오늘의 날씨·관심종목·일정·OPIc 기록 브리핑
  • 소식 — 날씨(news.html)와 투자 시세·경제 뉴스(stocks.html)
  • 학습 — 웹 제작 10단계 가이드, OPIc 모의고사, 단어장, 코드 노트
  • 제작 — 생활 앱 모음(learn.html), 실습 게임 45개(game.html)
  • 도구 — 숨어 있던 생활 앱을 한곳에서 열기(tools.html)
  • 기록 — OPIc 추이·일정·게임 최고 기록(records.html)
  • 소통 — 게시판·공지·실시간 대화(접속 중인 사용자만 표시)
  • 자료 — 내 자료(files.html), 공용 데스크톱 도구(apps.html)
  • 계정 — 일정, 로그인, 마이페이지, 설정, 안내

데이터 보관 위치

  • 이 브라우저 — 할 일·메모·지출·단어장·코드 노트·OPIc 기록·테마·관심종목
  • 서버 계정 — 게시글·댓글·자료실 파일·그림·일정·게임 점수·대화
  • 브라우저 데이터를 지우면 로컬 기록이 사라지므로 설정에서 JSON으로 백업하세요.
  • 회원 탈퇴는 마이페이지에서 비밀번호 확인 후 즉시 처리됩니다.

최근 업데이트

  • 리듬 게임: 매 판 새 곡, Level 1~6, 레벨별 랭킹, 시드 공유 링크
  • 대화: 접속 중인 사용자만 표시, 입력 중 표시, 안 읽음 배지, 5초/5건 전송 제한
  • 게임: 45개 전체 스모크 검사, 모바일 솔리테어 레이아웃, 타이머 게임 일시정지
  • 계정: 비밀번호 확인 후 즉시 탈퇴
  • 기록: 게임·일정·OPIc 기록을 한 화면에서 확인

문제가 생겼을 때

  • 화면이 비어 보이면 새로고침하거나 오프라인 안내를 확인하세요.
  • 로그인이 풀리면 로그인 후 다시 시도하세요.
  • 게임이 열리지 않으면 인터넷 연결을 확인하세요(게임 스크립트는 처음 열 때 내려받습니다).
