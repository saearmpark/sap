VS Code 설치

VS Code는 HTML·CSS·JavaScript·Python을 한 창에서 작성하고 실행할 수 있는 무료 편집기입니다. 이 단계가 끝나면 프로젝트 폴더를 열고, 코드를 저장하고, 브라우저로 결과를 확인할 수 있습니다.

난이도 · 입문 예상 시간 · 15분 준비물 · Windows PC

1. VS Code 내려받기

  1. 공식 사이트에 접속합니다. 브라우저에서 code.visualstudio.com을 엽니다. 검색 결과의 광고 사이트가 아니라 공식 주소인지 확인하세요.
  2. Windows용 설치 파일을 받습니다. Download for Windows 버튼을 누르면 VSCodeUserSetup-x64-....exe 파일이 받아집니다. 관리자 권한이 없어도 설치되는 User Installer면 충분합니다.
  3. 설치 파일을 실행합니다. 약관에 동의하고, 설치 위치는 기본값을 그대로 두어도 됩니다.
  4. 추가 작업을 체크합니다. 아래 항목을 켜 두면 편리합니다.
    • 바탕 화면에 바로 가기 만들기
    • 탐색기 파일/폴더의 상황에 맞는 메뉴에 Code로 열기 추가
    • 탐색기 폴더의 상황에 맞는 메뉴에 Code로 열기 추가
    • PATH에 추가 — 터미널에서 code 명령을 쓰려면 필요합니다.
주의

설치 중 “이 앱이 디바이스를 변경하도록 허용하시겠습니까?” 창이 뜨면 예를 누릅니다. 설치 후에는 VS Code를 한 번 실행해 초기 설정을 마칩니다.

2. 한국어와 필수 확장 설치

왼쪽 세로 막대의 네모 블록 아이콘(Extensions)을 누르거나 Ctrl + Shift + X를 누릅니다. 검색창에 아래 이름을 입력하고 Install을 누르세요.

확장용도설치 후
Korean Language Pack메뉴를 한국어로 표시재시작 후 언어 선택
Live ServerHTML을 로컬 서버로 미리 보기HTML 파일 우클릭 → Open with Live Server
Prettier - Code formatter들여쓰기·줄바꿈 자동 정리저장 시 자동 포맷(선택)
PythonPython 문법 강조·실행·디버깅06 파이썬 제작에서 사용

확장을 설치한 뒤에는 VS Code를 껐다 켜거나 Reload를 눌러 적용하는 것이 안전합니다. Python은 웹사이트 제작에 필수는 아니므로, 06단계를 진행할 때 설치해도 됩니다.

3. 프로젝트 폴더 열기

  1. 폴더를 엽니다. 상단 메뉴에서 파일 → 폴더 열기를 고르고 사이트 폴더(예: D:\sap)를 선택합니다. 파일 하나만 여는 것이 아니라 폴더를 여는 것이 중요합니다.
  2. 신뢰 여부를 확인합니다. “이 폴더의 작성자를 신뢰합니까?”가 나오면 내가 만든 폴더이므로 예, 작성자를 신뢰합니다를 누릅니다.
  3. 탐색기에서 파일을 확인합니다. 왼쪽 위 파일 아이콘을 누르면 index.html, assets 폴더 등이 보입니다. 보이지 않으면 상단의 폴더 이름을 눌러 올바른 위치인지 확인하세요.
  4. 새 파일과 폴더를 만듭니다. 탐색기 제목 줄의 새 파일 아이콘을 누르고 index.html을 입력합니다. images처럼 폴더가 필요하면 새 폴더 아이콘을 사용합니다.
  5. 저장합니다. 파일을 처음 저장할 때는 Ctrl + S를 누르고 위치와 이름을 확인합니다. 이후에는 같은 단축키로 바로 저장됩니다.

4. 터미널과 저장 습관

상단 메뉴 터미널 → 새 터미널 또는 Ctrl + `로 아래쪽에 터미널을 엽니다. 현재 폴더가 프로젝트 폴더인지 먼저 확인하세요.

PowerShell 
Get-Location
node --version
git --version

버전이 나오면 준비가 된 것입니다. 명령을 찾을 수 없다는 메시지가 나오면 해당 프로그램이 설치되지 않았거나 PATH에 없는 상태이므로, 설치 후 VS Code를 다시 실행하세요.

TIP

코드를 고친 뒤에는 Ctrl + S로 저장합니다. Live Server를 쓰면 저장하는 순간 브라우저가 자동으로 새로고침됩니다.

5. Live Server로 결과 확인하기

  1. 파일을 엽니다. 탐색기에서 index.html을 클릭합니다.
  2. 우클릭 메뉴를 엽니다. 편집 화면이나 파일 탭에서 마우스 오른쪽 버튼을 누릅니다.
  3. Open with Live Server를 선택합니다. 브라우저가 열리고 주소가 http://127.0.0.1:5500/index.html처럼 표시됩니다.
  4. 수정·저장·확인을 반복합니다. 코드를 바꾸고 저장하면 브라우저가 자동으로 갱신됩니다.
참고

file:///D:/sap/index.html처럼 파일을 직접 열면 일부 기능(서버 요청, 저장소)이 제한될 수 있습니다. 가능하면 Live Server 주소로 확인하세요.

6. 자주 하는 실수

  • 엉뚱한 폴더를 열었다 — 탐색기 맨 위 폴더명을 확인하고, 아니면 폴더 열기로 다시 엽니다.
  • 파일을 저장하지 않았다 — 탭의 점(●)은 저장되지 않은 상태입니다. Ctrl + S.
  • 확장이 안 보인다 — 설치 후 Reload 또는 VS Code 재시작이 필요할 수 있습니다.
  • 터미널 명령이 안 된다 — VS Code를 설치할 때 PATH 추가를 하지 않았다면 재설치하거나, Git·Node를 공식 설치 파일로 따로 설치합니다.

완료 체크리스트

  • VS Code를 설치하고 실행했다.
  • 한국어 팩과 Live Server를 설치했다.
  • D:\sap 폴더를 열었다.
  • 탐색기에서 새 파일·폴더를 만들고 저장할 수 있다.
  • 터미널에서 node --version과 git --version을 확인했다.
  • index.html을 Live Server로 열어 화면을 확인했다.
