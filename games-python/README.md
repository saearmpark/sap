# codestudio 게임제작 실습 (Python)

game.html의 "게임제작" 메뉴에 있는 STEP과 같은 순서로, 같은 게임을 Python(pygame)으로
직접 만들어보는 폴더입니다.

## 실행 방법

```bash
cd games-python
pip install -r requirements.txt
python tictactoe_pygame.py
```

- 클릭: 칸에 O/X 놓기
- `R` 키: 다시 시작
- 창 닫기: 종료

## 학습 포인트 (STEP 1: 틱택토)

- **게임 루프**: `while True:` 안에서 이벤트 처리 → 화면 그리기 → `clock.tick()`으로 속도 제한, 이 세 가지가
  거의 모든 게임의 기본 구조입니다. `game.html`의 JS 버전은 클릭할 때마다 다시 그리는 방식이라 별도 루프가
  없다는 차이도 비교해보세요.
- **좌표 → 칸 번호 변환**: 마우스 클릭 좌표(`x, y`)를 `CELL_SIZE`로 나눠 몇 번째 칸인지 계산하는 부분
  (`col, row = x // CELL_SIZE, y // CELL_SIZE`)이 이후 모든 게임에서 반복해서 쓰이는 패턴입니다.
- **승리 조건 판별**: 가로/세로/대각선 8가지 경우의 수를 리스트(`WIN_LINES`)로 미리 정의해두고 순회하는 방식은
  JS 버전과 동일한 로직입니다.

## STEP 2: 벽돌깨기

```bash
python breakout_pygame.py
```

- 마우스 또는 좌우 방향키: 패들 이동
- `R` 키: 다시 시작

학습 포인트:

- **매 프레임 갱신**: 틱택토는 클릭할 때만 화면이 바뀌지만, 벽돌깨기는 `clock.tick(60)`으로 초당 60번
  공 위치를 갱신하고 다시 그립니다. 이게 진짜 "게임 루프"입니다.
- **충돌 처리**: `pygame.Rect.colliderect()`로 공과 패들/벽돌이 겹쳤는지 검사하고, 겹치면 공의 방향(`dy`)을 뒤집습니다.
- **각도 조절**: 패들의 어느 위치에 맞았는지(`hit`)에 따라 좌우 방향(`dx`)을 바꿔서 조작감을 만듭니다.

다음 단계(슈팅게임)부터도 이 폴더에 파일을 추가해가는 방식으로 진행하시면 됩니다.


## STEP 4: 슬라이딩 퍼즐

```bash
python puzzle_pygame.py
```

- 마우스 클릭: 빈칸과 붙어있는 칸 이동
- `R`: 섞기 · `S`: 저장 · `L`: 불러오기

학습 포인트:

- **JSON으로 상태 저장/불러오기**: `save()`는 `json.dump()`로 리스트를 `puzzle_save.json` 파일에 그대로 저장하고,
  `load()`는 `json.load()`로 다시 읽어옵니다. STEP 2(할일 관리)가 직접 만든 텍스트 형식(`0|내용`)을 썼다면,
  이번엔 JSON이라는 표준 형식을 씁니다. `game.html`의 JS 버전은 파일 대신 브라우저의 `localStorage`를 쓴다는
  차이도 비교해보세요.
- **항상 풀 수 있는 상태로 섞기**: 숫자를 완전히 무작위로 섞으면 절반은 이론적으로 풀 수 없는 배치가 됩니다.
  그래서 "빈칸과 인접한 칸만 반복해서 바꾸는" 방식으로 섞어, 항상 풀 수 있는 상태를 보장합니다.
- **좌표 계산 재사용**: STEP 1(틱택토)에서 썼던 "클릭 좌표 → 칸 번호" 계산이 여기서도 그대로 쓰입니다.

이렇게 4단계를 마치면 게임 루프, 충돌 처리, 여러 개체 관리, 상태 저장까지 게임 개발의 기본기를 한 바퀴 돈 것입니다.
